First steps

  • Click the Hark button (bottom left) or press the Super key: Hark! There's the menu.
  • Open Hark toolbox (or type hark-tools) and choose Install ESP32 and Arduino cores.
  • Example projects are in ~/hark-examples.
  • Sense HAT without a Pi? Start sense_emu_gui and run sense-python rainbow.py.
  • Different language or keyboard? hark-language, or pick one on the login screen.

House rules

  • Network scans and Wireshark only on networks you have permission for.
  • The live session forgets everything on reboot: save your work to a USB stick, or install Hark.
